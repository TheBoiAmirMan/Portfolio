# پرتفولیوی امیرعلی کوهپایه

پرتفولیوی فارسی و راست‌به‌چپ برای معرفی فعالیت‌های مهندسی داده و تحلیل داده، با بخش‌های پروژه‌ها، نوشته‌ها، کتاب‌ها و ارتباط.

سایت با HTML، CSS و JavaScript ساده ساخته شده؛ دیتابیس، فریم‌ورک و مرحلهٔ build ندارد و روی GitHub Pages از ریشهٔ شاخهٔ `main` منتشر می‌شود.

## فایل‌ها

- `index.html`: معرفی، بخش‌ها و متن‌های اصلی
- `styles.css`: ظاهر و چیدمان واکنش‌گرا
- `content.json`: پروژه‌ها، نوشته‌ها و کتاب‌ها
- `app.js`: نمایش محتوای JSON و منوی موبایل
- `.nojekyll`: انتشار مستقیم فایل‌های استاتیک

## افزودن محتوا

در `content.json`، آیتم‌های دلخواه را به آرایهٔ مربوط اضافه کنید. آرایه‌های فعلی عمداً خالی‌اند و اطلاعات نمونه، سابقه یا کتاب ساختگی منتشر نشده است. فقط `title` اجباری است. فیلدهای دیگر اختیاری‌اند. اگر `url` وارد نشود، لینک نمایش داده نمی‌شود.

نمونهٔ زیر فقط الگوی ساختار است؛ عنوان‌ها و توضیح‌ها را با محتوای واقعی جایگزین کنید:

```json
{
  "projects": [
    {
      "title": "عنوان پروژه",
      "category": "مهندسی داده",
      "description": "معرفی مسئله و کاری که انجام شده است.",
      "tags": ["Python", "SQL"],
      "url": "https://github.com/OWNER/REPOSITORY",
      "linkLabel": "مشاهدهٔ کد ↗"
    }
  ],
  "writing": [
    {
      "title": "عنوان نوشته",
      "category": "یادداشت",
      "description": "خلاصهٔ نوشته.",
      "date": "2026-10-06",
      "url": "https://example.com/article"
    }
  ],
  "books": [
    {
      "title": "نام کتاب",
      "author": "نام نویسنده",
      "status": "در حال مطالعه",
      "description": "یادداشت کوتاه دربارهٔ کتاب.",
      "url": "https://example.com/book-note"
    }
  ]
}
```

لینک‌ها می‌توانند آدرس کامل وب یا مسیر نسبی یک صفحه در همین سایت باشند. متن‌ها با `textContent` رندر می‌شوند؛ HTML داخل JSON اجرا نمی‌شود. نمایش محتوا با پروتکل HTTP/HTTPS انجام می‌شود، پس برای مشاهدهٔ محلی فایل را مستقیم با `file://` باز نکنید.

## اجرای محلی

از داخل پوشهٔ پروژه:

```bash
python -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید. این دستور فقط برای بررسی محلی است؛ GitHub Pages فایل‌ها را مستقیم سرو می‌کند.

پس از تغییر فایل‌ها و ثبت commit روی `main`، GitHub Pages نسخهٔ تازه را منتشر می‌کند. آدرس سایت: https://theboiamirman.github.io/Portfolio/
